# 文档索引

## 目录约定

`docs/` 固定五个位置，不另建第四类目录：

- `docs/README.md`：总索引与命名规则；
- `docs/架构全景图.md`：系统上下文、部署拓扑与运行时链路；
- `docs/需求/{四位需求号}/`：五件套与 `assets/`、`sql/`；
- `docs/流程/{两位编号}-{中文名称}-v{N}.md`：流程图、时序图、状态机；
- `docs/功能/{两位编号}-{中文名称}.md`：架构、功能清单、术语、限制、选型。

契约冻结输入独立放在仓库根 `contracts/`，与 `docs/` 平级，不进入文档五分类。

## 命名与版本

- 流程文档：`{两位编号}-{中文名称}-v{N}.md`，H1 为 `# {编号} {名称}（v{N}）`；只有流程变化才新增版本。
- 需求文档：`{四位需求号}-{中文名称}-{文档类型}.md`；需求 SQL 放 `需求/{需求号}/sql/{表名}.sql`。
- 结论必须能回到代码、路由、配置或运行命令；未实现/外部完成/待确认步骤需标注。
