# 02 功能清单

> 文档编号：02
> 项目：Go版人脸核验服务
> 状态：已实现
> 证据基线：`docs/需求/0001/0001-Go版人脸核验服务-实施方案.md`
> 统计口径：以基线当前注册的路由、Worker 任务与 dev 页面为准；未注册项不计入。

## 1. HTTP 路由

| 模块 | 方法与路径 | 鉴权 | 功能 | 状态 |
| --- | --- | --- | --- | --- |
| 挑战 | `POST /v1/challenges` | JWT | 下发动作、帧数、nonce 与过期时间 | 已实现 |
| 动作 | `POST /v1/action-check` | JWT | 单动作实时预检 | 已实现 |
| 档案 | `POST /v1/enrollments` | JWT | 活体与动作校验后建立或覆盖档案 | 已实现 |
| 档案 | `POST /v1/verifications` | JWT | 活体与动作校验后做档案 1:1 | 已实现 |
| 主体 | `GET /v1/subjects/{subject_id}` | JWT | 查询档案状态与模型版本 | 已实现 |
| 主体 | `DELETE /v1/subjects/{subject_id}` | JWT | 合规删除档案、索引与对象 | 已实现 |
| 开发 | `POST /dev/token` | 无 | 本地签发 dev JWT | 已实现 |
| 开发 | `GET /dev/face-test.html` | 无 | 本地 H5 采集页 | 已实现 |
| 健康 | `GET /health/live` | 无 | 存活探针 | 已实现 |
| 健康 | `GET /health/ready` | 无 | 就绪探针与模型版本 | 已实现 |

## 2. 未注册接口

以下路径在基线当前版本中未注册，本期不实现：`POST /v1/sessions`、`POST /v1/matches`、`POST /v1/liveness-checks`、`POST /v1/identifications`、`POST /v1/documents`、`GET /v1/operations/{id}`、`POST /v1/results/{jti}/consume`。

## 3. Worker 任务

| 任务 | 触发方式 | 功能 | 状态 |
| --- | --- | --- | --- |
| 会话过期清理 | 每 1 分钟 | 将超时未完成会话置 `expired` | 已实现 |
| 留存清理 | 每 5 分钟 | 删除过期证件记录；硬删超过保留期的已删除档案 | 已实现 |
