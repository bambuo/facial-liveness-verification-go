## 5. 风控

| 项 | 实现 | 说明 |
| --- | --- | --- |
| 分钟配额 | Redis | challenge 创建前拦截 |
| 活体失败锁定 | Redis `face:liveness:fail/lock` | `real` 清零，`spoof`/`fuzzy` 累计；达上限 429 |
| 无脸帧 | 记 0 分并计攻击帧 | 无帧或全无脸返回 `NO_FACE` |
| 请求体上限 | challenge/action-check/enroll/verify | 单帧超限 422 `LOW_QUALITY` |
| 启动 fail-fast | 非法数字/布尔、负留存、缺主密钥 | 直接启动失败 |
