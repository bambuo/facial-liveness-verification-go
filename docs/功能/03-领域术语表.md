## 1. 主术语

| 主术语 | 英文 / 代码映射 | 定义 | 允许别名 | 避免用法 |
| --- | --- | --- | --- | --- |
| 租户 | `tenant` / `face_tenants` | 接入方固定编号；单系统通常只有一条 | 接入方、客户 | 多租户、组织 |
| 主体 | `subject` / `face_subjects` / JWT `sub` | 业务用户 ID；档案归属 | 用户、人员 | 账号（与开发者账号混淆） |
| 档案 | `profile` / `face_profiles` | 加密人脸向量与模型版本 | 模板 | 人脸库（易与 1:N 混淆） |
| 会话 | `session` / `face_verification_sessions` | 一次核验尝试的状态与结果 | 验证会话 | 登录会话 |
| Challenge | `challenge`（Redis） | 一次性动作序列与帧数凭证 | 挑战 | 令牌（与 JWT 混淆） |
| 动作校验 | `action-check` | 逐帧预检，不消费 challenge | 预检 | 活体（两者不同） |
| 活体 | `liveness` / PAD | 判断真人 vs 攻击呈现 | 防伪 | 动作校验 |

| 结果令牌 | result token | 返回给客户端的 JWT | 结果 JWT | 访问令牌 |
| 开发者 | `developer` / `developers` | 接入平台的一方账号；持有 API Key | 接入方账号 | 租户 |
| 审核员 | `reviewer` / `verification_reviewers` | 人工复核人员 | 复核员 | 管理员 |
| 管理后台 | `admin` | 平台运营与审核界面 | 运营后台 | 开发者门户 |
| 移动交接 | `handoff` / `mobile_handoff_sessions` | 桌面发起、移动端完成的会话 | 交接 | 跳转 |

| 可验证凭证 | VC / `verifiable_credentials` | 可撤销、可验证的凭证 | 凭证 | 证书文件 |
| 保险库 | vault / `identity_vault` | 加密属性存储与分享 | 属性库 | 密码库 |
| AML | `aml_screenings` | 反洗钱名单筛查 | 名单筛查 | 风控评分 |
| 合规规则 | `compliance_rulesets` / `compliance_rules` | 可配置规则集与评估 | 规则引擎 | 风控 |
| 风险评分 | `verification_risk_scores` | 速度/地理/设备等风险分 | 风控分 | 信用分 |
| 去重指纹 | `dedup_fingerprints` | 防重复提交的指纹 | 指纹 | 人脸特征 |
| 再验证计划 | `reverification_schedules` | 周期性重新核验 | 复验 | 重试 |
| 数据保留 | `dataRetention` | 按策略清理过期数据 | 保留期 | 备份 |
| 引擎 | engine | 重 ML 提取服务（6 端点） | ML 服务 | API |
| 契约冻结 | contract freeze | 154 接口/31 表/错误码/鉴权矩阵签字 | M0 | 需求确认 |
| 契约级 1:1 | contract parity | 对外行为逐条一致；允许实现替换 | 完全复刻 | 代码级复刻 |

## 2. 指标

| 指标 | 含义 | 方向 | 局限 |
| --- | --- | --- | --- |
| FAR | 错误接受率（冒名通过） | 越低越好 | 依赖阈值与人群 |
| FRR | 错误拒绝率（本人被拒） | 越低越好 | 与 FAR 权衡 |
| EER | FAR = FRR 时的错误率 | 越低越好 | 单点概括，掩盖尾部 |
| ROC | FAR 与 TAR 的曲线 | 曲线下面积越大越好 | 需要足够样本 |
| APCER | 攻击呈现被接受率 | 越低越好 | 依赖攻击类型覆盖 |
| BPCER | 真人被拒率 | 越低越好 | 与 APCER 权衡 |
| WER | 语音识别词错误率 | 越低越好 | 依赖语料与口音 |

## 3. 易混对照

| 对照 | 区别 |
| --- | --- |
| `subject` vs `user` | 前者是 Go 基座主体；后者是 idswyft 用户表（31 表之一） |
| `tenant` vs `developer` | 前者是接入方编号（.NET 语义）；后者是 idswyft 账号模型 |
| `face_verification_sessions` vs `verification_requests` | 前者是 Go 会话；后者是 idswyft 验证请求（39 列） |
| 活体 vs 动作校验 | 活体判断攻击；动作校验判断指令完成度 |
| 活体 vs 深伪 | 活体针对呈现攻击；深伪针对生成/换脸 |
| PAD vs 风控 | PAD 是模型判定；风控是速度/地理/设备等策略 |
| 1:1 vs 1:N | 前者是比对；后者是检索（本期不做） |

## 5. 状态口径

- **已实现已验证**：有代码 + 实际运行/测试证据。
- **已实现未验证**：有代码，但缺集成测试、压测或真机证据。
- **未实现**：idswyft 有、Go 侧没有。
- **基线不做**：明确移出范围（1:N、pgvector、cgo、Node sidecar、cloud `platform/*`）。
