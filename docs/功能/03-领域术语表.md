# 03 领域术语表

> 文档编号：03
> 项目：Go版人脸核验服务
> 状态：已实现
> 证据基线：`docs/需求/0001/0001-Go版人脸核验服务-实施方案.md`

| 术语 | 代码映射 | 定义 |
| --- | --- | --- |
| 租户 | `face_tenants`、`tenant` claim | 共用平台的一个业务方；所有数据带 `tenant_id` 隔离 |
| 主体 | `face_subjects`、`sub` claim | 租户内的核验对象，用业务用户 ID 关联，不保存业务资料 |
| 档案 | `face_profiles` | 主体的加密 128 维特征与模型版本；同主体最多一个 active 档案 |
| challenge | `face:challenge:{id}` | 一次性采集凭证，绑定租户、主体、模式、设备，默认 300 秒 |
| 会话 | `face_verification_sessions` | challenge 对应的处理记录，保存状态、分数与活体指标 |
| 动作序列 | `actions` | `straight` 打底，加 `turn_left`、`turn_right`、`mouth_open` 的随机子集 |
| 动作段 | `frames_per_action` | 每个动作对应的连续帧数，运行时限制 2–8 |
| 帧数 | `frame_count` | 动作数乘每段帧数，最大 15 |
| 活体投票 | `LivenessVote` | 多帧结果汇总：任一攻击帧为 spoof，否则按 live 占比判 real 或 fuzzy |
| 最低活体分 | `clarity` | 多帧 Softmax 索引 1 分数的最小值 |
| live 占比 | `reality` | live 帧数除以有效判定帧数 |
| 瞳距 | `eyeDist` | YuNet 双眼关键点欧氏距离 |
| yawRatio | `FrameMetric.YawRatio` | 鼻尖 X 减双眼中点 X，再除以瞳距；负值朝画面左，正值朝右 |
| mouthRatio | `FrameMetric.MouthRatio` | 鼻尖到双嘴角中点的距离除以瞳距；张嘴时相对基线增大 |
| 比对分数 | `score` | SFace 两个 L2 归一化特征的余弦相似度，以点积计算 |
| 模型版本 | `mica-sface-128d-1.0.2` | 引擎常量；写入档案，跨版本禁止比对 |
| 结果令牌 | `verification_token` | HS256 JWT，通过时签发，由业务后端验签与消费 |
| 快照对象键 | `detail_json.keys` | 审计中记录的对象存储键，用于主体删除时清理原图 |
| 幂等键 | `Idempotency-Key` | 当前版本接受但未接入幂等存储 |
