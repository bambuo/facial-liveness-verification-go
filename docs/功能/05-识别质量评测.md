# 05 识别质量评测

> 文档编号：05
> 项目：Go版人脸核验服务
> 状态：已实现
> 证据基线：`internal/eval`、`cmd/eval`、`internal/adapter/onnx/testdata/`、LFW 200 人基线、AxonData PAD 基线

## 1. 工具用途

`cmd/eval` 是独立的离线评测命令，不启动 HTTP 服务，也不依赖 PostgreSQL/Redis。它加载人脸引擎，按清单计算：

- 同人配对与异人配对的余弦分数；
- FAR、FRR、TAR、EER、ROC AUC；
- 指定目标 FAR 下的推荐阈值与 FRR；
- 活体序列的最低分、均值，以及 APCER/BPCER；
- 明细 CSV 与汇总 JSON，可用于 CI 门禁。

## 2. 运行方式

```bash
go run ./cmd/eval \
  -manifest eval/manifest.example.yaml \
  -model-dir models \
  -out eval/out \
  -target-far 0.001 \
  -liveness-threshold 0.85
```

常用参数：

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| `-manifest` | 无 | 必填，YAML/JSON 清单 |
| `-model-dir` | `models` | 三个 ONNX 模型目录 |
| `-out` | `eval/out` | 报告输出目录 |
| `-target-far` | `0.001` | 目标误识率 |
| `-liveness-threshold` | `0.85` | 服务活体阈值 |
| `-max-impostor-pairs` | `0` | 异人配对上限，0 表示全部 |
| `-threshold-step` | `0` | 阈值步长，0 表示使用清单配置 |
| `-max-frr-at-target` | `-1` | FRR 门禁，负数表示不启用 |
| `-max-apcer` | `-1` | APCER 门禁，负数表示不启用 |
| `-max-bpcer` | `-1` | BPCER 门禁，负数表示不启用 |
| `-detection-threshold` | `0.9` | 检测阈值，应与服务保持一致 |
| `-nms-threshold` | `0.3` | NMS IoU 阈值 |
| `-analysis-threshold` | `0.6` | 特征与活体路径的检测阈值 |
| `-liveness-crop-scale` | `2.7` | 活体裁剪倍率 |

## 3. 清单格式

```yaml
identities:
  - id: person_001
    images: [path/1.jpg, path/2.jpg]
    meta: { age_band: "20-30", device: "iphone" }
  - id: person_002
    images: [path/3.jpg, path/4.jpg]

liveness:
  bona_fide:
    - id: live_001
      images: [path/live_1.jpg, path/live_2.jpg]
  attacks:
    - id: print_001
      label: print
      images: [path/print_1.jpg]

options:
  max_impostor_pairs: 200000
  threshold_step: 0.01
```

规则：

- 至少两个可检测的 identity，且至少一个 identity 含两张可检测图片，才能计算 FAR/FRR。
- 同人配对按 identity 内两两组合；异人配对按 identity 之间两两组合。
- 活体序列的最低分用于判定：`最低分 >= 阈值` 视为 live。
- 相对路径按清单所在目录解析；绝对路径直接使用。
- 图片只在本机读取，不上传。

## 4. 输出

| 文件 | 内容 |
| --- | --- |
| `report.json` | 汇总指标、阈值、EER、AUC、活体指标、错误列表 |
| `scores.csv` | 每对图片的类型、身份、路径与分数 |
| `roc.csv` | 各阈值下的 FAR/FRR/TAR |
| `liveness.csv` | 每个活体序列的最低分、均值与错误 |
| `liveness_metrics.csv` | 各阈值下的 APCER/BPCER |

退出码：

- `0`：评测完成且未触发门禁；
- `1`：评测失败或指标未达标；
- `2`：清单或参数错误。

## 5. 自动化与 CI

```bash
go test ./internal/eval
go run ./cmd/eval -manifest <ci 清单>.yaml -out eval/out \
  -target-far 0.001 -max-frr-at-target 0.05 \
  -max-apcer 0.01 -max-bpcer 0.05
```

建议：

- 每次提交跑小样本回归集，防止预处理或模型漂移；
- 夜间跑全量评测集，报告作为 CI artifact；
- 目标 FAR、FRR、APCER、BPCER 写入门禁参数，不达标阻止合并；
- 评测集与产出报告不得包含真实人脸原图。

### 6.2 活体 / PAD

| 数据集 | 规模 | 获取 | 许可/商用 |
| --- | --- | --- | --- |
| OULU-NPU | 55 人、5,940 段视频 | [官方页面](https://sites.google.com/site/oulunpudatabase/) | 需签署 EULA，研究用途 |
| CelebA-Spoof | 625,537 张、10,177 人 | [GitHub](https://github.com/ZhangYuanhan-AI/CelebA-Spoof) | 仅非商业研究，禁止再分发 |
| CASIA-FASD / Replay-Attack / MSU-MFSD | 打印、翻拍等 | 各机构申请 | 研究用途 |
| WMCA / HQ-WMCA | 多攻击类型 | 申请 | 受控许可 |
| FaceForensics++ / Celeb-DF | Deepfake | 申请 | 仅研究用途 |

结论：

- 上述公开数据集适合做**相对比较和研发回归**，不能直接作为商业合规证据。
- 商业上线评估应使用自有授权采集数据，或采购允许商业使用的数据集。
- PAD 若要对外声明符合 ISO/IEC 30107-3，需要按标准协议采集攻击样本，或使用具备资质的测试实验室。

## 7. 当前能力最佳档位

### 7.1 本机基线

LFW 1:1（200 个身份、605 张图，767 对同人、181,943 对异人）：

| 指标 | 中文含义 | 值 |
| --- | --- | --- |
| EER | 等错误率：FAR 与 FRR 相等时的错误率 | 2.996% |
| AUC | ROC 曲线下面积：0.5 为随机，1.0 为完美 | 0.988190 |
| FAR / FRR | 误识率 / 拒识率：不同人误放行 / 同一个人被拒绝 | 0.1396% / 4.1721% |
| 目标 FAR 0.1% | 目标误识率下的阈值与对应拒识率 | 阈值 0.36，FRR 4.4329% |

AxonData PAD（29 段真人、120 段攻击视频，8 类攻击）：

| 阈值 | APCER（攻击放行率） | BPCER（真人拒绝率） |
| --- | --- | --- |
| 0.85 | 24.17% | 17.24% |
| 0.90 | 18.33% | 17.24% |
| 0.91 | 16.67% | 17.24% |
| 0.92 | 15.83% | 17.24% |
| 0.95 | 10.83% | 24.14% |

0.91 附近达到 APCER 与 BPCER 的最佳平衡。

### 7.2 推荐配置

高风险场景推荐：

```bash
FACE_LIVENESS_THRESHOLD=0.91
FACE_ACTIONS_COUNT=3
FACE_FRAMES_PER_ACTION=5
FACE_ACTION_VERIFY_ENABLED=true
# 高风险可选
FACE_MATCH_THRESHOLD=0.36
```

说明：

- 0.91 相比默认 0.85，在不增加真人拒绝率的情况下降低攻击放行率。
- 动作校验仍是必要门槛，用于拦截静态照片和简单重放。
- 样本只有 29 段真人、120 段攻击；该档位不构成商业 PAD 合规结论。
- 高仿真面具仍有约 16.7% 的通过率，需要更强的 PAD 模型、设备风控和人工复核补充。

## 8. 当前限制

- 已完成 LFW 200 人与 AxonData 29 段真人 / 120 段攻击的本地基线；样本仍有限，不能直接外推到业务人群。
- 指标为点估计，未计算置信区间；小样本结果不能外推。
- 未按人群、设备、光照拆分报告；清单已预留 `meta`，后续可扩展分片统计。
- 活体指标按序列最低分聚合，与服务端“任一攻击帧即 spoof”一致；未评估视频级时序模型。
- LFW 与 AxonData 均只用于研究/内部验证；AxonData 为 CC BY-NC 4.0，不能作为商业合规证据。
- 当前 PAD 基线中，高仿真面具在 0.91 阈值下仍有约 16.7% 的通过率，需要更强的 PAD 模型、设备风控与人工复核补充。
