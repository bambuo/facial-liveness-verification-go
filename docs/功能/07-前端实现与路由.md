本地开发：

```bash
cd frontend
bun install
bun run dev
# 独立端口联调
VITE_DEV_PORT=5180 VITE_API_TARGET=http://localhost:8090 bun run dev
```

默认 `http://127.0.0.1:5173`，`/api` 代理到 `http://localhost:8080`；独立端口时由 `VITE_API_TARGET` 指定 Go API。

## 3. 鉴权与数据

- 开发者：邮箱 OTP 登录成功后，后端返回 Bearer token 并写入 HttpOnly `iv_developer_session` Cookie；刷新页面由 Cookie 恢复会话。
- 审核员：`/api/auth/reviewer/otp/*` 登录，写入 HttpOnly `iv_admin_session` Cookie。
- 管理端页面统一使用 `credentials: 'include'`；CSRF 端点同时返回 `csrfToken` 与 `csrf_token`。
- API Key、handoff token、session token 仍按 `X-API-Key` / `X-Handoff-Token` / `X-Session-Token` 鉴权。
- 管理端统计由后端把 12 值状态折叠为 `total/pending/verified/failed/manual_review`；列表补 `id` 与状态分类。
- 状态展示按 shared 12 值映射；`final_result` 单独展示。

## 4. 关键交互

- **用户核验**：初始化 → 正面文档 → 可选背面 → 自拍/活体 → 可选语音挑战与 WAV 上传 → finalize/status。
- **移动交接**：生成 handoff 链接后本地绘制二维码，倒计时、复制链接并在手机完成后轮询。
- **相机采集**：`getUserMedia` + canvas 抓帧；OpenCV.js 已本地托管于 `/vendor/opencv.js`。
- **管理端**：验证列表/筛选/详情 Drawer/审核，开发者列表，统计概览。
- **开发者端**：API Key、Webhook、统计图表、Page Builder 配置与预览。
- **凭证**：解析 JWT 的 `jti`，浏览器内验签与状态查询；身份卡支持 PNG 与 ISO ID-1 PDF 导出。
- **文档**：`/docs/markdown` 由 Go API 返回 Markdown，前端按标题、代码、表格与列表渲染。

## 5. 自动检查

```bash
cd frontend
bun run type-check      # tsc --noEmit
bun run build           # Vite 生产构建
bun run test            # Vitest
bun run lint            # ESLint 10 flat config
bunx antd lint ./src    # antd 规范检查，0 告警
FRONTEND_URL=http://localhost:5173 bun run check:routes
```

`check:routes` 使用 Playwright Chromium 打开 24 条必需路由，检查 HTTP 状态、正文长度与控制台错误；未登录管理页的 401 探测不计为失败。

## 6. 复用与去品牌约束

- 直接复用参考 React 页面与组件，不维护第二套 Vue 实现。
- 交互组件统一使用 Ant Design 6：Button、Input、Select、Form、Table、Modal、Drawer、Card、Statistic、Tag、Alert、Segmented、Upload、ColorPicker 等；不再新增原生 button/input/select 表单控件。
- `ConfigProvider` 跟随 `data-theme` 切换明暗算法，跟随语言切换 en/zh-CN locale。
- UI、i18n、`index.html` 元信息、Logo 与文档示例中的参考品牌统一替换为 Identity Verification。

## 7. React 19 与语法规范

- 函数组件使用显式 props 类型，不使用 `React.FC`。
- 需要转发 ref 的组件直接声明 `ref` prop，不使用 `forwardRef`。
- Hooks 与类型使用命名导入，不使用 `React.useX` / `React.ReactNode` 命名空间写法。
- 浏览器环境变量使用 `import.meta.env`，不使用 `process.env`。
- 异常分支使用 `catch (caught: unknown)` 并显式收窄，不使用 `catch (err: any)`。
- 构建目标为 `ES2023` / `baseline-widely-available`；Tailwind 4 使用 `@tailwindcss/vite`，不再保留 PostCSS/Tailwind 3 链路。
- 已移除未使用依赖与历史示例页；锁文件为 `bun.lock`。
- Bun 1.4 统一安装与脚本运行；TypeScript 使用最新兼容版 6.0.3（TypeScript 7 与 typescript-eslint 8 尚不兼容）。
- 外部 OpenCV.js 改为本地静态资源，避免 CDN 跨域与离线不可用。
- 参考页面结构、字段、空/错/加载状态与交互保持原样。
