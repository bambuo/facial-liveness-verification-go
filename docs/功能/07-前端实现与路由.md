## 3. 鉴权与数据

- 开发者：`X-API-Key` 保存在 localStorage（`iv_api_key`）；开发者 OTP 仅用于邮箱验证，不签发长期 JWT。
- 管理端：`/api/auth/admin/login` 返回 Bearer token，保存在 `iv_admin_token`；路由守卫拒绝未登录访问。
- 采集页：`X-Session-Token` 保存在 `iv_session_token`，由初始化或 handoff 会话获得。
- 所有请求经 `src/lib/api.ts` 注入；401 时清除 admin token。
- 状态展示按 shared 12 值映射；`final_result` 单独展示。

## 4. 关键交互

- **用户核验**：初始化 → 正面文档 → 可选背面 → 自拍/活体 → 可选语音挑战与 WAV 上传 → finalize/status。
- **相机采集**：`getUserMedia` + canvas 抓帧，上传 `/extract/live`，展示人脸置信度、活体与真实深伪结果；需要 HTTPS 或 localhost。
- **管理端**：验证列表/筛选/详情 Drawer/审核，开发者列表，阈值读取/保存/预览/重置。
- **开发者端**：API Key 连接、月度统计、Key 列表/创建、Page Builder 配置与预览。
- **凭证**：解析 JWT 的 `jti` 并调用公开状态接口。

`check:ui` 使用 Playwright Chromium，注入 admin token/API key 并 mock 管理端接口，验证 5 个需要鉴权的页面。

## 6. 1:1 复刻约束

- 统一使用 **Vue3 + Arco Design Vue**，不引入第二套 UI 库。
- 页面结构优先使用 Arco 标准组件：`a-layout`、`a-menu`、`a-page-header`、`a-card`、`a-grid`、`a-statistic`、`a-table`、`a-form`、`a-upload`、`a-drawer`、`a-modal`、`a-result`、`a-empty`、`a-descriptions`、`a-typography`。
- 不重复实现 Arco 已提供的按钮、卡片、表格、表单、分页、抽屉、弹窗、上传、通知等基础组件。
- 参考页面逐页复刻，保留信息层级、字段、枚举、交互和空/错/加载状态；仅将视觉 token 映射到 Arco 主题变量。
- 截图基线必须先对齐参考页面，再作为回归基线；当前 `tests/baselines` 只是本实现自身的回归基线，不代表 1:1 达标。
