1. 单元测试：`go test ./internal/...`。
2. 纯 Go 构建：`CGO_ENABLED=0 go build ./cmd/api ./cmd/worker`，检查产物动态库。

5. 基线对账：同一组图片分别调用 Go 与 .NET，比较分数与动作几何。

### 4.2 人脸流水线

| 指标 | Go 版 | .NET 基线 | 差值 |
| --- | --- | --- | --- |
| Jay_3 动作几何 yaw | 0.023 | 0.019 | 0.004 |
| Jay_3 动作几何 mouth | 0.467 | 0.463 | 0.004 |
| Jay_3 录入 → Jay_4 核验 score | 0.6118 | 0.62328 | 0.0115 |

差值来自图像缩放与关键点插值的实现差异（Go `x/image/draw` 与 Skia 低质量滤波），不影响 0.35 阈值的判定；两者均通过。若后续要求更严格的分数一致性，可替换为重采样的 Skia 等价实现。

## 5. 发现并修复的问题

| 问题 | 处置 |
| --- | --- |
| onnx-gomlx 将 SFace 的 initializer 同时当作 graph input，要求调用方传入全部权重 | 本地补丁：解析输入时排除 initializer |
| onnx-gomlx 缺 PRelu 与 Dropout | 本地补丁按 ONNX 规范实现：PRelu 使用 opset 16 的 `Less + Where + Mul` 函数体；Dropout 按推理语义输出输入、mask 全 true，并拒绝 `training_mode=true`。规范用例见 `internal/adapter/onnx/testdata/` |
| MiniFASNetV2 batch 维为动态 | 编译时固定为 1 |
